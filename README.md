# NX-AI

离线 AI 语音与视觉交互项目，包含核心程序、模型资产、运行配置、独立测试台和项目文档。当前项目基线版本为 **v0.0.0**。

## 项目组成

| 部分 | 用途 |
| --- | --- |
| 核心程序 | 串联音频采集、唤醒、语音识别、对话、语音播放、图像处理及主控通信 |
| 模型资产 | 保存模型文件、词表、配套数据和模型运行器 |
| 独立测试台 | 提供网页操作、功能调试、运行观测和测试记录 |
| 测试与工具 | 提供自动检查、测试素材及部署、启停、资源检查脚本 |
| 项目文档 | 记录需求、接口约定、执行方案、阶段报告和交付说明 |

## 配置与运行入口

- `Config/target.json`：核心程序运行配置，包括音频设备、模型路径、模型服务地址、主控通信及日志位置。
- `Testbench/Config/bench.json`：独立测试台服务配置。
- `pyproject.toml`：Python 版本要求、依赖声明和测试入口配置。
- `Testbench/测试台.cmd`：Windows 下连接目标机、启动及关闭测试台的菜单入口。

本机模型位于 `NX-AI/Models/`，正式配置中的 `/home/mylin/Desktop/Nuo/models` 是目标机路径，两者不能直接替换。

本次仅整理本机工程。远程目标机仍沿用原有的小写部署路径；Windows 菜单中的远程路径与目标机配置保持原值。整理后的脚本使用新的本机目录结构，覆盖远程部署前需另行确认迁移，不能直接用本机旧副本覆盖目标机。

启动前请阅读[测试台启动与关闭指南](Docs/测试台/启动与关闭.md)，核对目标机地址、部署路径和设备状态。指南中的历史实测记录不代表整理后的本机副本已完成实机验证。

## 文件维护约定

- 核心程序、配置、模型资产、测试素材和文档分别放入对应目录。
- 新建自有管理目录采用英文首字母大写或清晰的中文名称。
- Python 包、第三方资产、虚拟环境和历史归档内部结构保留原有命名。
- 移动文件或调整目录时，同步修改相关路径引用和文档链接。
- 保留检查点、原始证据及可恢复资料，避免直接覆盖唯一副本。
- 文档不记录密码、密钥等敏感信息。

## 变更日志

项目变更统一记录在 [CHANGELOG.md](CHANGELOG.md)，较新的记录放在前面。

```markdown
## 更新版本-更新日期-变更简述

- 具体变更内容。
- 其他需要说明的改动。
```

版本号采用 `vX.Y.Z`，日期采用 `YYYY-MM-DD`。功能更新按实际变更调整版本号；纯文档更新沿用当前功能版本号。

当前基线统一为 `v0.0.0`，主控通信协议标识 `interaction.v0.1` 独立维护。只记录实际完成的变更，计划事项不作为已完成内容写入。

## Git 仓库

远程仓库：[NuoAug/NX-AI](https://github.com/NuoAug/NX-AI)，默认分支为 `main`。

版本管理包含核心程序、配置、文档、测试代码、合成测试素材、模型清单及构建说明。`.gitignore` 用于排除本机环境、模型和运行器二进制、原始运行证据、备份归档、恢复资料及真实说话人录音；这些文件仍保留在本机，克隆仓库不会获得它们。

模型部署参见 [模型资产说明](NX-AI/README.md)，缺少真实音频或模型的测试需补齐本地资料后执行。仓库中的目标机地址及 Linux 路径来自原部署，换机时按实际环境调整。

功能版本提交使用 `vX.Y.Z`；纯文档提交使用 `docs: 简述`，不增加功能版本号。当前首次提交以 `v0.0.0` 建立代码基线。

# 运行手册（目标板）

适用版本：AI_Eyes 视觉语言交互子系统 0.1.0（2026-11-11 交付）
目标机：Orin NX 16GB / JetPack 7.2.1 / L4T 39.2.1 / Ubuntu 24.04.4
项目根：`/home/mylin/Desktop/Nuo`

## 1. 目录约定

| 路径 | 内容 |
|---|---|
| `src/aieyes/` | 交互子系统源码（单进程 asyncio + 音频采集线程） |
| `config/target.json` | 目标板配置（模型根、llama-server 地址、证据目录） |
| `models/` | 模型资产（GGUF、ASR/TTS/KWS/OCR/声纹/VAD）；仓库侧唯一来源为 `NX-AI/models/`，校验清单 `NX-AI/manifest.json` |
| `third_party/llama.cpp/build/bin/llama-server` | 自建 CUDA 版运行器 |
| `.venv/` | 目标板 Python 依赖（见交付清单的 requirements 锁） |
| `tools/` | 启动/停止/探针/回放/冒烟工具 |
| `evidence/` | JSONL 证据（每次运行追加） |
| `logs/service.log` | 交互服务标准输出/错误 |

## 2. 启动（离机可独立完成）

```bash
cd /home/mylin/Desktop/Nuo
bash tools/run_aieyes.sh
```

脚本行为：先检查 llama-server（`127.0.0.1:8080/health`），未运行则用
`tools/serve_llama.sh` 拉起并等待就绪；再以 `setsid nohup` 启动交互服务
（`python -m aieyes.main --config config/target.json`）。两条进程都与 SSH 会话解耦，
断开开发机不影响运行。

成功标志：输出 `LLAMA_READY` 与 `SERVICE_STARTED pid=...`；`logs/service.log`
出现 `aieyes 交互已启动`；`evidence/interaction.jsonl` 新增 `startup` 记录。

## 3. 健康检查

```bash
curl -s http://127.0.0.1:8080/health           # {"status":"ok"}
pgrep -fa 'aieyes.main' | head                  # 交互服务进程
tail -n 5 evidence/interaction.jsonl            # 最新交互事件
ss -tnp | grep -v 127.0.0.1                     # 应为空：不依赖外网
```

## 4. 停止

```bash
cd /home/mylin/Desktop/Nuo
bash tools/stop_aieyes.sh
```

先 SIGTERM 交互服务（正常收尾、证据写入 `shutdown`），再停 llama-server。
强制停止：`pkill -f aieyes.main; pkill -f '[l]lama-server'`。

## 5. 冷启动（重启后）

设备重启不会自动拉起服务（当前未安装 systemd 单元）。重启后按第 2 节执行一次
`bash tools/run_aieyes.sh` 即可；llama-server 首次加载约 3.3 s，TTS 首次合成约
4.8 s 属正常冷启动。

## 6. 回退与恢复

| 情况 | 处理 |
|---|---|
| 交互服务异常退出 | 看 `logs/service.log` 与 `evidence/interaction.jsonl` 末尾事件；修复后重新 `run_aieyes.sh` |
| llama-server 未就绪 | `bash tools/serve_llama.sh` 前台运行看错误；模型/投影路径见配置 `models.root` |
| 想回到无交互服务状态 | `bash tools/stop_aieyes.sh`；两个进程都会退出，无后台残留 |
| 相机被占用（阶段 3/4） | `fuser /dev/video4` 查占用进程；释放后重试 |
| 音频设备占用/异常 | 当前目标板只有 HDMI 输出与 APE 采集，无麦克风；接上 USB 声卡后在 `config/target.json` 的 `audio.input_device/output_device` 指定设备名 |
| 本地回放代替真人 | `python -m aieyes.main --config config/target.json --replay fixtures/questions`（只验证软件链，不证明真人可用） |

## 7. 复现输入与快速自检

```bash
# 环境/资产探针（阶段 0）
.venv/bin/python -m aieyes.probe --config config/target.json --out evidence/phase0/probe.json

# 整栈内存/时延（阶段 7）
.venv/bin/python tools/mem_probe.py --config config/target.json \
  --image tests/fixtures/images/text_cn_price.png \
  --image2 tests/fixtures/images/scene_red_square.png

# 30 分钟持续检查（阶段 8，回放输入）
.venv/bin/python tools/soak_test.py --config config/target.json --minutes 30

# 全量回归（需要 llama-server 在跑）
PYTHONPATH=src .venv/bin/python -m pytest -q tests/unit tests/integration
```

## 8. 已知限制（不冒充通过）

- 没有麦克风与扬声器：真人开口、盒上听到、真实回声/AEC、真人三主线均未现场验收。
- 真实主控未接入：合同层有替身集成（C01–C12 + 引擎桥），真实主控并行未验证。
- 2 小时电池/散热联合验收需整机与主控组织，未执行。
- llm 服务为单槽（`--parallel 1`）、批 `256/128`，为满足 4 GiB 内存上限的取舍。

## 目录迁移说明

2026-11-15 整理本机目录，主要路径对应关系如下。

| 原路径 | 当前路径 |
| --- | --- |
| `config/`、`src/`、`tests/`、`tools/` | `Config/`、`Src/`、`Tests/`、`Tools/` |
| `testbench/` | `Testbench/` |
| `tests/unit/`、`tests/integration/`、`tests/fixtures/` | `Tests/Unit/`、`Tests/Integration/`、`Tests/Fixtures/` |
| `NX-AI/models/`、`NX-AI/runtime/`、`NX-AI/tools/` | `NX-AI/Models/`、`NX-AI/Runtime/`、`NX-AI/Tools/` |
| `Docs/` 下的功能说明与待确认清单 | `Docs/需求/` |
| `Docs/` 下的 DeepSeek 完整方案 | `Docs/方案/` |
| `testbench/` 下除 README 外的 Markdown 文档 | `Docs/测试台/` |

`Testbench/` 下的自有管理子目录同步首字母大写。Python 包、第三方资产、虚拟环境及历史归档内部结构保持原样。

## 记录口径

- 历史报告、原始证据、检查点及恢复资料中的旧路径和测试结论保留，不改写为当前验证结果。
- 历史资料中的项目根相对路径可按上表定位；远程绝对路径仍指向原部署。
- 本次未迁移远程目标机，也未运行设备测试。远程工程与本机整理副本应分别核对。
- 本地测试台只包含实际已有的文件；启动指南提到的 `serve_model.sh`、`stop_model.sh` 在本地 `Testbench/Scripts/` 中缺失，不应将本机副本视为完整远程部署。

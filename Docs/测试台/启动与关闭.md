## 启动顺序

### 1. 本机 PowerShell：登录目标机

```powershell
ssh -o HostKeyAlias=192.168.2.72 mylin@10.59.209.90
```

输入密码，登录后执行下一步。不把密码保存到脚本或本文。

### 2. 第一个 SSH 窗口：启动模型服务

```bash
cd /home/mylin/Desktop/Nuo
bash testbench/scripts/serve_model.sh
```

看到监听 `http://127.0.0.1:8080` 后保持窗口打开。此测试台入口使用独立目录内的 Q8 视觉投影副本和已核验的资源参数，不修改正式启动脚本及原始权重。已经有模型服务时不要重复启动。

### 3. 第二个本机 PowerShell：登录并启动测试台

```powershell
ssh -o HostKeyAlias=192.168.2.72 mylin@10.59.209.90
```

登录后：

```bash
bash /home/mylin/Desktop/Nuo/testbench/scripts/start.sh
```

输出 `started` 或 `already running` 后进入下一步。此命令只启动网页服务，不开启外设。

### 4. 第三个本机 PowerShell：建立隧道

```powershell
ssh -N -o HostKeyAlias=192.168.2.72 -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 127.0.0.1:18780:127.0.0.1:18780 mylin@10.59.209.90
```

输入密码后无输出通常正常，保持窗口打开。

### 5. 本机浏览器访问

打开 [测试台](http://127.0.0.1:18780/)。只保留一个控制页面；其他页面只读时，在空闲状态点击“取得控制”。

当前自动验证使用已有录音、实景图片和无声播放替身，不调用实际摄像头、麦克风或扬声器。请勿将回放结果视为真人收音、现场唤醒或实际出声验收。

需要恢复真实外设交互时，先连接目标机的外接摄像头及蓝牙音频，并在系统中确认输入和输出均可用。测试台菜单可以保持系统默认，或明确选择在线外设；设备未连接时先处理连接状态。摄像头没有限定型号。

点击预览、测试或调试才会使用外设。不要同时执行 `tools/run_aieyes.sh` 启动第二套独立交互服务。

## 关闭顺序

1. 页面点击“停止”，关闭预览，等待本轮任务结束。
2. 在第二个 SSH 窗口停止测试台：

```bash
bash /home/mylin/Desktop/Nuo/testbench/scripts/stop.sh
```

3. 在第一个运行模型的 SSH 窗口按 `Ctrl+C`，停止模型。也可以在 SSH 提示符下执行以下命令，脚本只停止测试台记录且核对了归属的模型进程；有活动测试时拒绝停止。模型若被队友使用，先协调，不要关闭共享服务。

```bash
bash /home/mylin/Desktop/Nuo/testbench/scripts/stop_model.sh
```
4. 在第三个隧道窗口按 `Ctrl+C`，关闭转发。
5. SSH 提示符下执行 `exit`，退出登录。

仅关浏览器或 SSH 窗口不等于停止后台测试台服务。模型前台启动时保持窗口打开；不要同时运行两套模型或两套交互服务。

## 常见状态

- 网页可打开但按钮只读：关闭多余页面，空闲时取得控制。
- 未发现蓝牙音频：先在目标机连接，并确认麦克风方向存在；只有高音质播放能力的设备不等于具有可用麦克风。
- 摄像头被占用：查看进程名和 PID，不结束队友进程，不强制抢占。
- 本机18780被占用：先核对是否已有隧道；不要重复建立或随意结束未知进程。
- 首次通过新 IP 连接时，`HostKeyAlias` 沿用原目标机记录。若报告主机密钥变化，先核对机器身份，不关闭主机密钥校验来绕过。
- IMX708 返回 Remote I/O error：停止采集，检查相机连接/供电/驱动；不要重启共享相机服务来影响队友。

# 视觉语言交互子系统本机修复核验（2026-11-15）

依据 `Docs/需求/视觉语言交互子系统待修复清单.md`、`Docs/MCPT/AI_Eyes项目背景与主线验收标准.md` 和最近目标机暂停归档。目标机代码仍以 `/home/mylin/Desktop/Nuo/testbench/` 为权威；本机 Git 起点为 `v0.0.0`，本轮未提交或同步目标机。

## 清单核对

原 42 项对历史失败、已修待复验及缺少证据的项目总体区分正确。实际代码发现遗漏：同一轮综合测试取消结束后，迟到的启动错误回调仍可把 `interrupted` 覆盖为 `failed`，已补为第 43 项并修正。本机顶层旧版与候选版本、脚本缺失、回归数字等描述已随本轮进度更新。学校名 OCR、充电宝租借柜定向修复有历史证据，不当作仍在复现的错误；功能泛化和交付版本仍未验收。

## 本机改动

- `Testbench/` 源码、网页和软件用例对齐最近暂停归档；保留项目更新后的大小写适配脚本和 README，不覆盖正式 `Src/`、`Config/` 或模型权重。
- 并入否定控制反馈修复；综合运行与插话调试入口传递模型取消事件；取消结果记录为 `interrupted`。
- 综合运行结束不再启动 0.2 秒后的进程自退出，沿用现有五秒空闲回收；启动前及装配各阶段检查取消；空闲回收在真正停 worker 的锁内复查是否已有新任务；迟到启动回调不覆盖已结束状态。
- 补齐测试台模型启停脚本；该脚本依赖目标机既有 Q8 投影文件和 Linux 运行环境，本机尚不能完整启动。
- `Testbench/Tests` 中四处跨测试模块导入改用相对导入，适配本机大写目录与目标机小写目录；无需再在测试命令中临时注册 `tests` 别名，262 项测试可直接收集。

## 验证

正式分类器下四种“别／不要关或开麦克风”均为 CHAT，候选返回“不更改麦克风设置”；方法询问保留聊天。8 项针对性逻辑测试通过。当前本机 `Testbench/Tests` 软件回归为 **252 passed、5 failed、5 skipped、11 subtests passed，12.78 秒**，原始日志 `Testbench/Local_resume_20261115/main/local_project_final.log`。5 项失败仍是 Windows socket 取消两项、默认目标机路径下缺 VAD/KWS 两项、POSIX 路径断言一项；5 项跳过涉及 Linux flock 和 `/proc`。这些结果不等于目标机软件回归或端到端立即重试通过。

本机原生测试收集在相对导入修正后为 **262 tests collected，0 collection errors**。上一轮完整执行使用临时 `tests` 别名；导入修正只影响测试模块之间的引用，未重跑与之无关的功能用例。
直接受影响的控制回归、设备选择和 worker 状态用例复跑 **9 passed，2.91 秒**；剩余一处路径断言仍列在上述 Windows 平台失败项中。

## 验收结论

**未达到整体主线验收标准。** 本机没有完成真人三条主线、有效首声与真人停声计时、完整 CPU/GPU 去重资源、KWS 近音误唤醒、短词 ASR、模型多轮回复准确率、视觉多图泛化、30 分钟持续运行和主控／电池散热联合测试。历史小样曾显示热聊和单图响应超出初筛目标，不能用本机软件测试销项。单功能每轮最多 5 分钟，全功能联动每轮最多 30 分钟；真实设备每轮由用户启动。目标机恢复后先逐文件核对当前版本，再同步本轮改动、复测受影响路径及剩余问题，不以本机副本直接覆盖队友改动。

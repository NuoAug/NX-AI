### 新发现并修复

- 工作进程路径此前虽然指向`.venv/bin/python`，但对整个路径调用`resolve()`会解引用Python符号链接，实际进入系统Python，导致HTTP调试中的OCR报`No module named onnxruntime`。现改为仅做词法绝对路径规范化，保留虚拟环境解释器路径。
- 调试结束回调传入的是DebugContext，原代码却仅按DebugRun对象身份清理，导致下一轮提示已有调试运行中。现正确匹配所属上下文，并忽略旧任务完成回调。
- 旧工作进程退出/清理与新任务启动发生竞争。现隔离旧进程回调，空闲回收不能终止新活动任务。
- 长文本调试原为整段生成，停止不能及时生效；现在改用流式生成并检查取消。停止状态先发送，避免迟到的“停止中”覆盖最终“已中断”。

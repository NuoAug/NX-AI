## 2026-11-16 离线语音交互自然化（软件层）

- 目标：自然中文、按任务阶段理解、减少重复和机械确认；先打通双图比较，再覆盖读字/找物/视觉追问/聊天入口。未新增功能、未改主控合同、未提交/推送。
- 双图等待：准备说法（换好了/现在是另一件/第二个放上去了/来，看这个/可以看了）推进拍摄；保持说法（等一下/我还没换好/先别拍/这个还没摆正/第二个还没好/不要继续）只保持等待，不取图、不聊天。否定先于肯定，避免“还没换好”里的“换好”被当完成。

- 暂停与结束：`先放着，聊点别的` → `paused/user_pause`，保留 A/B 证据；`算了，不比了` → `closed/user_abandon`，并清空引擎当前比较引用，之后“继续”不复活。

- 插问：`第一件叫什么` / `第二件多少钱` 用对应帧回答，任务状态不变；`刚才那个多少钱` 两帧都在时先问一次“第一件还是第二件”，再按短回答取帧。
- 纠正：`不是第二个，是第一个` / `刚才说反了` 只交换 A/B 帧归属（及证据组 image_ids）后按原问题重答；`第二张不清楚，重来一次` 只重拍 B，A 沿用；未点名重拍才问哪一件。比较完成后点名重拍改为“复用另一位置 + 重取该位置”，旧任务不被改写。

## 2026-11-16 无屏可用性整改（软件层）

- 目标：视障用户不看网页、不背口令，用正常语速完成已有任务，并知道状态、能纠正和恢复。本轮只做代码/文字入口/文件回放/真实模型集成，未做真人视障体验。
- P0 整句意愿仲裁：等待拍摄时先去掉引用内容，再按分句取最后有效意愿；疑问、不确定、否定、过去完成态优先于“拍/准备/第一件”。真实入口验证：
  - “第一件是什么” → 回答第一件，不取图；
  - “好了，不过先别拍”“别继续拍” → 保持等待；
  - “先别拍……现在好了，可以拍了” → 拍；
  - “准备好了没有我不知道” → 只问一次“你是说第一件已经放好了吗？”；
  - “我刚才说‘继续’，不是现在让你拍” → 不取图；
  - “第一件是什么，放好了” → 先回答问题，不抢拍。
- 全局控制先于任务层：清除/停止/静音/紧急不会被“好了”吞掉；“取消比较”仍结束比较，裸“取消”仍全局停止。
- 改指代/换归属/重拍分开：上一轮问第二件后“不是第二个，是第一个”改为回答第一件，不交换 A/B；只有上一轮完整比较后才交换归属；无归属证据时只问“改指代还是对调”。问“重拍哪一件”后只答“第一件/第二件”即可执行。
- 状态反馈：比较等待/暂停/失败时“你在等什么/到哪一步了”直接答实际阶段；无比较任务时答“我在听你说”。“先别拍”第一次带用法，之后只说“我等你”。

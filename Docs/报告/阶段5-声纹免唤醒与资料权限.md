## 1. 本阶段实际可用

1. **说话人核验**：campplus 中文 16k 模型注册（最多 5 段、每段 ≥800ms 短样本拒绝）与核验；本人得 VERIFIED，他人得 MISMATCH，未注册得 UNAVAILABLE。
2. **免唤醒话题窗口**：正常回答播完并进入 T17 倾听超时后，若已注册声纹且未静音，开 15 分钟话题窗口（T21），保持麦克风聆听、关闭唤醒词监听；窗口到期自动退出回待机。
3. **候选准入**：窗口内开口先做声纹与“是否对系统发话”准入——可信本人 + 明确发话 → 直接受理；声纹明确不匹配 / 非发话 / 无话题窗口 → 安静忽略；声纹不确定 → 提示重新叫“小冰”，一次 15s 重入窗口（同类提示 30s 内最多一次）；声纹不可用 → 退回显式唤醒；自开口起 71s 预算（T19 三段）超出即释放。
4. **资料权限**：声纹核验通过后的 5 分钟内才允许“继续/恢复”旧看图任务、才允许“清空资料”；否则明确拒绝。
5. **清除动作**：清除对话历史、图片任务与帧缓存、TTS 缓存、当前播放；清除后旧任务不可恢复。
6. **兼容**：未注册声纹时整套免唤醒与资料权限不启用（`app.py` 打警告），显式唤醒链路不受影响。

## 6. 差距与风险

1. **真人声学验证缺失**（无麦克风/扬声器）：误接纳/漏接纳率、设备播音干扰下的准入、拒绝后显式重入等 b 出口项只有软件层证据。
2. “对设备发话”判定 `_looks_directed` 是词表/标点启发式，未用真实语音校准，可能把旁说误判为发话（有 15s/30s 冷却兜底）。
3. 声纹阈值 0.65 来自文件素材（本人 0.72–0.82、他人 ≤0.40），噪声/远场需现场重新校准。
4. 资料权限覆盖对话历史、图片任务/帧缓存与 TTS 缓存；**未删除磁盘证据文件**（证据保留用于验收，清除语义已在报告注明）。
5. 部署需要用户提供“经同意”的注册语音样本（每段 ≥800ms），当前 `models/speaker/enroll` 未预置。
6. 免唤醒的窗口末端回放、15s 重入均为软件模拟（单测），未做真人窗口末尾提问验证。

## 七、风险与失败记录

1. **无麦克风/扬声器**：真人声学证据（首声实际出声、停声、AEC 真实回声）无法取得 → 阶段 1 b/c、阶段 7 真人、阶段 8 整机联合受阻。
2. **llama-server 常驻内存偏高**（≈3.9 GB）：需在阶段 7 前做参数/加载策略优化并复测峰值。
3. llama.cpp 构建期 `third_party/llama.cpp` 曾被外部清空一次（原因未查明，models 未受影响），已重传重建；交付前锁定版本并备份源码。
4. 目标机 ffmpeg 无 AAC 解码器；`录音.zip` 转码改用 gstreamer。
5. CUDA 构建需在脚本内显式 `PATH`/`CUDACXX`（非交互 SSH 环境无 `/usr/local/cuda/bin`）。
6. KWS 首帧冷启动 2.56 s，已用 `warmup()` 消除；真实设备首次唤醒仍需实测。
7. VLM 默认 chat 模板带 thinking，`content` 为空；调用侧必须显式关闭 thinking（已在客户端配置处理中）。
8. 工作目录当前非 git 仓库，版本回退依赖文件快照；交付前需确定版本管理方式。

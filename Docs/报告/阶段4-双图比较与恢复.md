## 实际可用

- “这两个哪个贵？”→ 录音识别为 COMPARE → A/B 各取一张图（T09 10s 预算、T10 每位置 3 次）→ OCR 价格同口径比较 → 中文播报差异，不提交聊天模型。
- 比较任务上限 2 个未完成任务；超出时播“现在有两个没看完的看图任务，要先结束一个才能比新的。”，不再取图。
- 任务被打断（播报/思考中插话）→ 任务标记 paused，已取帧保留；说“继续…”时复用缓存帧，不重新取图。
- 失败/超时：T11 预算内超时→“这次比较没看完，你说‘继续’我再接着看。”并进入 T13；其它异常→“两张图我没能比出来，要不换个问题？”；两图都没读到内容→“两张图我没看清，没法比较。”
- 比较结论只按同一口径的项目给结论（价格/日期/颜色），读不到明确说“没读到、这次没比”，不编造。

## 已知问题与差距

1. **跨历史图比较未接**：方案要求“与历史图比较”只分析旧图、不扣取图次数、不启 T08、结论受较早截止约束；当前只会用本次任务帧，历史图复用未实现。
2. **翻面/换物/局部新观察流程未接**：T06 额外等待（120s/剩 30s 提醒）、翻面提示、局部重拍后只更新单边，均未在状态机实现；当前只有“重拍最多 3 次”的基础取图预算。
3. **打断时点细分不足**：方案列了 5 个打断时点（准备/取图/分析/已成文/半句已播）各自恢复动作；当前统一按 paused + 复用帧处理，仅验证了“分析前暂停→继续”这一条路径。
4. **图像任务 15min 提醒/收尾未接**：`CompareTask` 有 deadline 字段，但状态机没有到期提醒与到期释放播报。
5. **现场验证缺失**：无麦克风/扬声器，未做真人双商品实拍；相机低光质量门只能走降级路径。
6. 口述价格×数量路由（属阶段 3 遗留，见阶段 3 报告）仍未接。
7. 两字唤醒词对合成音偶发漏检（KWS 调参列阶段 7）。

## 1. 本阶段实际可用

1. **TCP 合同服务端**：交互侧作为服务端监听（默认 `127.0.0.1:18700`，`ContractConfig.enabled` 打开），主控作为客户端；4 字节大端长度 + UTF-8 JSON，单连接双向多路复用；非法帧/超大帧/坏 JSON 关闭该连接且服务端继续接新连接。
2. **握手**：连接建立后交互侧出站 `capabilities.get` 协商版本/能力/时钟域；版本不对或时钟域不同则记录拒绝原因（`contract.clock_mismatch`），本实现按合同拒绝跨时钟域时效数据。
3. **入站能力**：`capabilities.get`、`interaction.status.get`、`output.cancel` 三个请求 + `guidance.event` 事件由引擎真实应答；应答经合同 schema 严格校验（16 类消息、13 错误码）。
4. **状态快照**：`interaction.status` 返回模式（idle/listening/processing/speaking/degraded）、音频输入/输出状态、队列长度（image_tasks、guidance_pending）、服务表（kws/asr/tts/vlm/ocr 版本与状态）、内存（`/proc/self/status` VmRSS/VmHWM，`sampling=on_demand_proc_status`）、`metrics_window`（未测时为 null 窗口）。
5. **紧急引导**：`guidance.event` 支持 emergency/navigation/information；去重、过期丢弃、supersedes 替代、live 证据模式时钟域校验；紧急事件在播报/思考中抢占（停声 → 播引导 → 恢复倾听），普通播报结束后再补播暂存的导航/信息提示。
6. **播放状态回放**：每段播放发出 `playback.status`（queued/started/completed/cancelled/failed），带 `source_event_id`/`source_request_id`/`segment_index`/`generation`/`priority`/`start_basis`/`reason_code`；本地语音回合无主控请求号时使用可识别的 `local-turn-{generation}` 作为来源，不伪造主控请求。
7. **取消**：`output.cancel` 支持 guidance_event / ordinary_turn / ordinary_session 三种范围，回报 device_stopped / queue_cleared / compute_ended 与 basis（estimated）。

## 4. 实测数字（目标板）

- 握手：`contract.handshake {versions: ["interaction.v0.1"], clock_ok: true}`；夹具（主控替身）clock_id 与交互侧一致。
- 状态：空闲时 `mode=idle`，`queues.image_tasks=0`，`memory.sampling=on_demand_proc_status`。
- 紧急抢占：普通播报中收到 `guidance.event(ev-emergency-1, priority=emergency, interrupt_policy=preempt)` → `guidance.preempt {preempted: "speaking"}` → `guidance.done` → `guidance.recovered`；主控侧收到该事件对应的 `playback.status` queued/started/completed 三条。
- 取消：`output.cancel(scope=ordinary_turn)` → `device_stopped=true, queue_cleared=true, compute_ended=true`，basis=estimated。
- 播放状态来源：普通回答使用 `source_request_id=local-turn-{generation}`；引导播放使用 `source_event_id=ev-emergency-1` + priority。

## 7. 已知差距与风险

1. **真实主控未接入**：出口 c 不可判定；b 只验证了“软件替身主控 + 假播放”的抢占路径，真实推理占用期间抢占、真实主控重连/心跳未验证。
2. **心跳/序号/失联**：合同要求心跳丢失、序号倒退时撤销实时状态并重握手；当前只记录 connect/disconnect 与 epoch，无心跳定时器与序号倒退检测。
3. **guidance 恢复出口**：合同 12.4 表要求按场景选唯一恢复出口，本实现统一“恢复倾听”，属于简化。
4. **四个交互→主控能力未实现**（取主控帧/场景事实/目标关联/动作下发），capabilities 如实标 false 并列入 unimplemented。
5. **负载 flake**：`test_slow_handler_times_out_client_but_connection_survives` 在高负载全量跑时偶发失败（隔离通过），属测试容差问题。
6. **相机被其他程序占用**：目标板上 `/home/mylin/Desktop/Eyes/spatial_check/...` 进程会占 `/dev/video4`，真机相机用例可能 skip。
